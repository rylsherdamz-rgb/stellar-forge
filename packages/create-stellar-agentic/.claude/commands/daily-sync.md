# /daily-sync

Morning briefing for the Stellar Forge.

1. Read `data/projects/` for active project context
2. Check `data/inbox/` for new tasks or feature requests
3. Read `data/logs/reflections/` for last session's completion status
4. Check `data/deployments/` for deployed contract status
5. Run `git status` for uncommitted changes
6. Generate a summary:
   - Active project and milestone
   - Pending tasks from inbox
   - Last session's blockers and next actions
   - Uncommitted changes or pending deployments
   - Suggested priority for today
7. Append the briefing to `data/logs/daily/<date>.md`
